## AI / RAG Knowledge

I understand the main RAG pipeline:

1. Collect documents
2. Split documents into chunks
3. Generate embeddings
4. Store embeddings in a vector database
5. Convert a user question into an embedding
6. Retrieve relevant documents
7. Add retrieved context to the prompt
8. Send the prompt to an LLM
9. Generate the final answer

I have implemented a small RAG system manually and am also learning to use LangChain to handle retrieval and orchestration.
